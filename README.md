# TabularStudio

TabularStudio 是一款 Windows 本地桌面工具，用于完全离线处理 Excel 表格，主要面向 `.xlsx` 文件。

## 核心功能

MVP 只包含两个已确认功能：

1. **格式统一**  
   把来源表格整理成统一格式后导出。
2. **数据匹配**  
   在表格之间按已确认规则匹配数据并导出结果。
