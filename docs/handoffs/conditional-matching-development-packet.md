## 实现范围

1. 可选主表筛选开关，默认关闭；启用时选择主表列并输入非空指定值，例如「是」。沿用现有匹配条件列表设置 B/C/D 与对照表三列的映射，返回字段沿用现有选择。
2. Core 在联合匹配前判断主表参与条件，不符合的行保留并写未参与匹配状态，返回字段留空。
3. 原有标准化开关、空键、重复键、唯一匹配、源文件保护与输出覆盖确认继续生效。
4. 结果统计增加未参与匹配数量，统计总和等于主表数据行数。
5. 默认关闭时请求与结果行为兼容既有调用；不新增网络、数据库、批量、OR 或表达式。
