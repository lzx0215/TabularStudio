# 按位置比较表格数据

2026-09-10：Project Owner 确认新增此能力，并明确授权本次全部由 Codex 实现，跳过原角色交接、Issue 和 Gate 流程。此例外仅适用于本次功能，不替换其它任务流程。

## 行为

- 两个文件各选择一个工作表，也可选择同一工作簿的不同工作表。支持现有 `.xlsx`、`.xls`、UTF-8 `.csv`。
- 从 A1 开始比较，包含表头；按实际行列位置对应，不排序、不按键匹配、不做标准化。
- 比较数据值，忽略字体、颜色、边框、数字显示格式、列宽等样式。空格、大小写、文本和数字类型差异均保留。Excel 日期/时间按底层数值比较，因此仅改变日期显示格式不产生差异。
- 公式比较文件中已保存的计算结果，不比较表达式，不执行公式或外部链接；缺少缓存结果时失败并指出位置。结果不证明公式缓存是最新的，请先在 Excel/WPS 重新计算并保存。
- 空单元格与空字符串均视为无数据；末尾纯空行列、仅有样式的单元格忽略。中间空行列的位置仍参与比较。隐藏行列照常比较，合并区域仅比较实际存值的单元格。
- CSV 字段为文本；数字文本和 Excel 数字不相等。CSV 遵循既有离线解析限制。
- 任意位置不同即判定不一致，记录坐标、两边类型和值。一边缺失数据也记录差异。两张空表判定一致。
- 页面显示完整差异数量和前 1000 项；可将全部差异导出为新的 `.xlsx` 报告，附来源、范围、比较口径及结论。报告是新产物，不转换输入文件。
- 输入只读；报告不得覆盖输入或已有文件。取消/读取失败不能显示一致结论；更换文件或工作表后清除旧结果。

## 实现与验收

- Core：独立 `ITableComparisonService`、比较 DTO、`TableComparisonService`；复用本地格式适配器。App 只收集输入、调用 Core、显示结果。
- 导航新增“表格对比”；选择文件及工作表、开始、取消、查看差异、导出报告。
- 自动化覆盖三种输入格式及交叉组合、相同数据/不同样式、位置变化、类型/空格/大小写、空表/稀疏范围、公式缓存、报告重开与输入保护、异常/取消和 ViewModel 失效状态。
- Build、Core 与 App 自动化测试实际执行后记录结果；自动化不替代人工桌面验收，不使用桌面 GUI 自动化。
