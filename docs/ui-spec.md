## 1. 文档定位与原则

1. **唯一界面事实来源**：本文档记录 TabularStudio 已确认的 UI 页面方案，作为后续 WPF 页面实现、控件布局、交互逻辑与状态流转的唯一规范。
2. **严格对齐需求**：所有页面元素和交互行为严格遵循 `docs/requirements.md`，不得反向扩大产品范围。
3. **职责分离**：
   - 本文档只定义 UI 布局、控件类型、交互响应、视觉状态和错误反馈。
   - 不包含 ClosedXML 实现细节、数字/日期转换算法、匹配键比对算法、C# 接口/DTO 代码（算法由 `docs/processing-rules.md` 规定，调用约定由 `docs/contracts.md` 规定）。
4. **范围冻结**：仅覆盖已确认的 MVP 两个功能（**格式统一**、**数据匹配**），不包含未确认的第三方功能、在线服务或多余页面。

## 2. 全局窗口架构与 App Shell

### 2.1 窗口规格与视觉基调
- **窗口模式**：Windows 本地原生桌面应用窗口，支持最小化、最大化/还原、关闭。
- **窗口尺寸**：
  - 默认启动尺寸：`1100 × 720` 像素（居中启动）。
  - 最小尺寸：`960 × 640` 像素（防止低分辨率小屏幕下控件拥挤截断）。
  - 支持全屏/最大化，主内容区表格与配置卡片按比例自适应伸缩。
- **视觉风格**：简洁现代的 Windows 桌面工具风格，高对比度，清晰的信息分组卡片（Card / GroupBox 风格），遵循 8px 网格基准。

### 2.2 App Shell 布局骨架

界面整体采用经典的「左侧导航栏 + 右侧主内容区 + 底部状态条」布局：

```text
+---------------------------------------------------------------------------------------+
|  TabularStudio - 本地离线表格工具                                            [-] [口] [X] |
+---------------------+-----------------------------------------------------------------+
| [Logo] TabularStudio| [页面标题：格式统一 / 数据匹配]                                   |
|                     +-----------------------------------------------------------------+
| ------------------- |                                                                 |
| [Nav] 格式统一      |                                                                 |
|                     |                     右侧主工作区 (Content Area)                  |
| [Nav] 数据匹配      |            (动态呈现当前选中的功能页面，保持页面独立状态)         |
|                     |                                                                 |
|                     |                                                                 |
|                     |                                                                 |
| ------------------- |                                                                 |
| v0.1.0 MVP 本地离线 |                                                                 |
+---------------------+-----------------------------------------------------------------+
| 就绪状态 / 处理提示信息                                               [离线环境已就绪] |
+---------------------------------------------------------------------------------------+
```

### 2.3 导航系统与行为
1. **导航菜单项**：
   - **格式统一 (Format Normalization)**：处理单个 Excel 表格的格式清洗与规范化。
   - **数据匹配 (Data Matching)**：将主表与对照表基于多条件精确匹配并合并字段。
2. **导航切换行为**：
   - 点击导航项即时切换主工作区内容。
   - 切换功能页面时，保留各页面的输入状态与配置缓存，不因页面切换而丢失已选文件或已配置条件。
3. **底部全局状态栏**：
   - 左侧：当前系统全局状态或提示信息（例如：“就绪”、“正在处理...”）。
   - 右侧：环境标识（固定显示“离线环境已就绪”，强化离线安全认知）。

## 3. 功能一：格式统一 (Format Normalization)

用户选择 1 个 `.xlsx` 文件，对选定工作表做格式统一，并生成新文件。

### 3.1 页面布局线框图

```text
+---------------------------------------------------------------------------------------+

+---------------------------------------------------------------------------------------+
```

### 3.2 界面控件与交互说明

#### 3.2.1 数据源选择区
1. **文件选择输入框**：
   - 展现方式：单行文本框（只读显示完整物理路径）。
   - 交互支持：
     - 点击旁边的「浏览...」按钮，唤起 Windows 原生 `OpenFileDialog`，筛选条件固定为 `Excel 工作簿 (*.xlsx)|*.xlsx`。
     - 支持直接拖拽 `.xlsx` 文件至该区域；若拖入非 `.xlsx` 文件，显示阻断提示。
2. **工作表选择下拉框 (ComboBox)**：
   - 文件加载成功后自动解析并填充所有 Sheet 列表。
   - 默认自动选中第一个 Sheet。
   - 切换 Sheet 会触发数据预览区实时刷新。
3. **表头所在行设置 (NumericUpDown / 数字输入框)**：
   - 默认为 `1`。
   - 允许用户调整（最小值为 1，步长为 1）。
   - 当用户更改表头行时，数据预览表格的列标题将同步重算，并将所选行作为列头。

#### 3.2.2 标准化规则选择区
根据 `docs/requirements.md` 5.2 节已确认能力，提供多项标准化复选框（Checklist）：
1. **清理前后空格**：默认勾选。
2. **清理 Tab、换行、隐藏字符**：默认勾选。
3. **全角 / 半角统一**：默认勾选（针对字母、数字、英文符号）。
4. **Unicode 标准化**：默认勾选。
5. **普通数字安全统一**：默认勾选。
6. **明确日期安全统一**：默认勾选。
7. **保留前导 0 编号**：默认勾选。
8. **保留长数字文本**：默认勾选。
- **保护说明文本**：卡片底部常驻提示——*“处理时公式保持不变；尽量保留现有业务格式，不重新套固定美化模板。”*

#### 3.2.3 数据预览区
1. **预览表格 (DataGrid)**：
   - 加载当前选定工作表的前 20 行数据，用于快速确认表头位置和数据概貌。
   - 列标题由设定的「表头所在行」决定；若选定行内容为空，展示默认占位列名（如“第 A 列”）。
   - 只读模式，禁止就地编辑。支持横向与纵向平滑滚动。
2. **空态提示**：未加载文件前，居中展示浅灰色提示文字：“请先选择 Excel 文件以预览数据”。

#### 3.2.4 输出与执行控制区
1. **输出路径展示与配置**：
   - 默认文件名：`源文件名_格式统一.xlsx`。
   - 默认保存目录：源文件所在同级目录。
   - 提供「更改保存路径...」按钮，唤起 `SaveFileDialog`（限定 `.xlsx` 格式）。
   - **安全约束**：输出路径禁止与当前输入文件完全一致（若一致则禁用开始按钮并红字提示“输出文件不得覆盖源文件”）。
2. **进度反馈条 (ProgressBar)**：
   - 包含平滑进度条及进度文字描述（如“正在读取数据... 45%”、“正在写入新文件... 90%”）。
   - 处理未开始或空闲时显示 0% 或处于隐匿/平整状态。
3. **操作按钮组**：
   - **「开始格式统一」主按钮**：高亮重点按钮（Accent Button）。文件未加载或处理中时禁用。
   - **「打开生成文件」按钮**：成功后启用，使用 Windows 系统默认 Excel 软件打开结果文件。
   - **「打开所在文件夹」按钮**：成功后启用，在 Windows 资源管理器中打开并直接高亮选中该生成文件。
   - **「作为主表送入数据匹配 ->」按钮**：
     - 处理成功后高亮展示的快捷联动入口。
     - **交互动作**：点击后，程序自动切换左侧导航至「数据匹配」页面，并将刚生成的 `xxx_格式统一.xlsx` 文件完整路径自动填入数据匹配的「主表」文件选择框，自动触发主表 Sheet 加载，让用户无缝进入匹配流程。

## 4. 功能二：数据匹配 (Data Matching)

用户选择主表和对照表，按已确认条件进行精确匹配，并把对照表字段带回主表，生成新的匹配结果文件。

### 4.1 页面布局线框图

```text
+---------------------------------------------------------------------------------------+
| 数据匹配                                                  [帮助提示: 精确匹配 / 离线]   |
+---------------------------------------------------------------------------------------+
| [1. 输入表格选择] -------------------------------------------------------------------- |
| 主表 (Master):                                                                        |
|  文件: [ D:\data\2026业务流水_格式统一.xlsx           ] [浏览...]  [数据预览(20行)]   |
|  Sheet: [ Sheet1             [v] ]   表头所在行: [ 1 ]                                |
| 对照表 (Reference):                                                                   |
|  [ ] 与主表使用同一个文件                                                             |
|  文件: [ D:\data\客户字典表.xlsx                      ] [浏览...]  [数据预览(20行)]   |
|  Sheet: [ 客户信息           [v] ]   表头所在行: [ 1 ]                                |
+---------------------------------------------------------------------------------------+
| [2. 匹配条件配置 (固定 AND)]                     | [3. 选择带回字段 (从对照表)]        |
|  条件 1: [ 主表: 客户ID    [v] ] = [ 对照: 客户编码    [v] ] [删除] | 搜索字段: [ 手机        ] |
|    (且)                                          | [x] 全选  [ ] 反选  [已选 2/8 项]  |
|  条件 2: [ 主表: 机构代码  [v] ] = [ 对照: 机构号      [v] ] [删除] | +--------------------------------+ |
|  [ + 添加匹配条件 ]                              | | [x] 客户手机号                 | |
|                                                  | | [x] 客户地址                   | |
|  * 支持1~N条条件，所有条件必须同时满足(AND)      | | [ ] 注册时间                   | |
+--------------------------------------------------+ +--------------------------------+ |
| [4. 匹配规则与容错选项] -------------------------------------------------------------- |
|  [x] 自动修复常见匹配差异 (空格/全半角/文本数字/日期统一，仅用于比较，不改源数据)        |
|  [x] 生成匹配状态列 (列名: [ 匹配状态      ])                                         |
|  * 容错策略: 重复匹配键对应记录返回字段留空，状态记为“重复”；未匹配记录返回字段留空。    |
+---------------------------------------------------------------------------------------+
| [5. 当前匹配关系摘要] ---------------------------------------------------------------- |
|  匹配规则: [主表.客户ID = 对照.客户编码] 且 [主表.机构代码 = 对照.机构号]              |
|  带回字段: [客户手机号, 客户地址]  -->  追加至主表末尾 (重名自动追加 _匹配)             |
+---------------------------------------------------------------------------------------+
| [6. 输出与执行] --------------------------------------------------------------------- |
|  输出路径: [ D:\data\2026业务流水_格式统一_匹配结果.xlsx         ] [更改保存路径(S)...]     |
|  进度: [==================================== 100% ===================================] |
|  统计: 处理完成！总计: 1,580 行 | 成功匹配: 1,420 行 | 未匹配: 130 行 | 重复冲突: 30 行 |
|                                                                                       |
|  [  开始数据匹配  ]          [ 打开生成文件 ]          [ 打开所在文件夹 ]             |
+---------------------------------------------------------------------------------------+
```

### 4.2 界面控件与交互说明

#### 4.2.1 双表输入选择区
1. **主表 (Master Table) 设置**：
   - 文件选择框（只读路径 +「浏览...」按钮 + 拖拽支持）。
   - 工作表 ComboBox 与表头所在行 NumericUpDown。
   - 「数据预览」弹窗/侧边抽屉按钮：点击后以浮层或弹窗查看主表前 20 行样本。
2. **对照表 (Reference Table) 设置**：
   - **「与主表使用同一个文件」复选框**：
     - 勾选时：对照表文件路径自动锁定为主表路径，文件选择框与浏览按钮置灰禁用；对照表 Sheet 下拉框自动列出该文件下的所有 Sheet，便于跨 Sheet 匹配。
     - 取消勾选时：对照表可独立浏览选择另一个不同的 `.xlsx` 文件。
   - 对照表工作表 ComboBox 与表头所在行 NumericUpDown。
   - 「数据预览」按钮：可独立查看对照表前 20 行样本。

#### 4.2.2 动态匹配条件配置区 (Matching Conditions)
1. **条件列表结构 (1～N 条)**：
   - 每一行代表一组相等条件：`[主表字段下拉框] = [对照表字段下拉框] [删除按钮]`。
   - 主表字段下拉框：自动从主表选定 Sheet 与表头行中提取所有非空列名。
   - 对照表字段下拉框：自动从对照表选定 Sheet 与表头行中提取所有非空列名。
2. **多条件逻辑关系**：
   - 各条件之间固定展示 `AND`（且）连接符徽章，明确向用户传达“多条件必须同时精确匹配”。
3. **增删控制**：
   - 点击「+ 添加匹配条件」按钮可追加一行新条件。
   - 每行末尾提供「删除」图标按钮。
   - **约束**：至少保留 1 条匹配条件；当仅剩 1 条条件时，「删除」按钮置灰禁用。

#### 4.2.3 带回字段选择区 (Return Fields)
1. **字段检索与过滤**：
   - 顶部提供「搜索字段」即时搜索框（TextBox），输入关键字可实时过滤下方列表。
2. **多选列表 (CheckedListBox)**：
   - 完整列出对照表的所有可用字段。
   - 用户通过勾选框选择 1 个或多个需要带回的列。
   - 快捷操作按钮：提供「全选」、「反选」快捷文本按钮。
   - 统计指示：显示“已选择 M / N 项”。
3. **列名重名处理提示**：
   - 列表下方提示：*“若带回字段与主表现有列名重复，将自动重命名为 `列名_匹配`、`列名_匹配2`，不覆盖主表原有列。”*

#### 4.2.4 高级选项与容错配置
1. **自动修复常见匹配问题**：
   - 复选框，默认勾选。
   - 说明：比较匹配键时自动消除空格、全半角、文本/数值类型差异、日期格式差异，仅在内存比对时标准化，不破坏原有表格数据。
2. **匹配状态列**：
   - 复选框，默认勾选。
   - 列名配置框：默认为「匹配状态」，允许用户就地修改列名。
   - 状态取值说明：成功输出后该列将包含「匹配成功」、「未匹配」、「重复」、「匹配键为空」四种明确状态。
3. **重复与未匹配策略提示**：
   - 常驻说明：*“对照表出现重复匹配键时，对应主表返回字段留空，状态标为‘重复’，不自动抓取首尾行；未匹配时返回字段留空。”*

#### 4.2.5 匹配关系摘要预览条 (Summary Bar)
- 在核心配置区下方常驻单行卡片，动态拼接当前配置的人类可读摘要。
- 示例：`匹配关系：[主表.客户ID = 对照.客户编码] 且 [主表.机构代码 = 对照.机构号] | 带回 2 个字段 [客户手机号, 客户地址] | 启用状态列 [匹配状态]`。
- 用户一目了然，防止配错。

#### 4.2.6 输出与执行控制区
1. **输出路径配置**：
   - 默认文件名：`主表文件名_匹配结果.xlsx`。
   - 默认路径：主表文件同级目录。
   - 提供「更改保存路径...」按钮。
   - **安全约束**：禁止覆盖主表文件或对照表文件。
2. **执行按钮与进度反馈**：
   - 「开始数据匹配」主操作按钮。
   - 进度条及执行状态文本（例如：“正在建立对照表索引...”、“正在执行精确匹配 (800/1580)...”、“正在保存文件...”）。
3. **匹配结果统计指示卡片 (Success State)**：
   - 成功完成后，显式呈现统计面板：
     - **总处理行数**：如 `1,580` 行
     - **匹配成功行数**：如 `1,420` 行（绿色徽章）
     - **未匹配行数**：如 `130` 行（灰色/橙色徽章）
     - **重复冲突行数**：如 `30` 行（琥珀色/黄色徽章）
4. **后置快捷操作**：
   - 「打开生成文件」按钮。
   - 「打开所在文件夹」按钮。

## 5. 主要页面状态机规格 (Page States Specification)

为确保 WPF 界面数据绑定与视图状态（Visual State）逻辑严谨，对「格式统一」和「数据匹配」两页面分别统一规范 6 大生命周期状态。

### 5.1 状态枚举定义
1. **Initial / Empty**：初始空状态（无文件载入）。
2. **File Loaded**：文件已载入，正在解析表头或部分配置缺失。
3. **Ready**：配置完整就绪，等待用户触发执行。
4. **Processing**：正在离线处理，展示进度反馈并阻断配置改动。
5. **Success**：处理圆满完成，展示结果统计与文件快捷操作。
6. **Error**：处理失败或输入校验阻断，展示明确错误原因与引导。

---

### 5.2 格式统一页面：状态行为矩阵

| 状态 | 界面显示内容 | 可用控件 (Enabled) | 禁用控件 (Disabled) | 用户下一步操作 |
| --- | --- | --- | --- | --- |
| **Initial / Empty** | 路径框为空；预览区显示占位提示；进度条隐匿；结果卡片隐匿 | 导航栏、文件「浏览...」按钮、文件拖拽区域 | Sheet 下拉框、表头行输入、规则复选框、输出路径更改、开始按钮、打开文件相关按钮 | 点击「浏览」或拖拽 `.xlsx` 文件进入系统 |

| **Success** | 进度条到达 100%；展示绿色成功通知与耗时、行数；激活结果操作卡片 | 导航栏、重新选择文件/重新配置、「打开生成文件」、「打开所在文件夹」、「作为主表送入数据匹配」 | 开始按钮（如配置未改动则无需重复点击，保持就绪或重置态） | 1. 打开生成文件查看；<br>2. 打开所在文件夹；<br>3. 点击「作为主表送入数据匹配」直接流转 |

### 5.3 数据匹配页面：状态行为矩阵

| 状态 | 界面显示内容 | 可用控件 (Enabled) | 禁用控件 (Disabled) | 用户下一步操作 |
| --- | --- | --- | --- | --- |
| **Initial / Empty** | 主表与对照表路径均为空；匹配条件与带回字段区显示引导提示；执行区禁用 | 导航栏、主表「浏览」/拖拽、对照表「浏览」/拖拽、「与主表使用同文件」复选框 | Sheet 下拉框、表头行、添加条件按钮、字段搜索与多选列表、高级选项、开始匹配按钮 | 选择主表文件与对照表文件 |
| **File Loaded** | 两边文件及 Sheet 均已载入；字段列表已刷新；但尚未配置有效匹配条件或尚未选择带回字段 | 导航栏、两边文件选择与 Sheet 选择、表头行微调、条件添加/删除、字段搜索与勾选 | 开始数据匹配按钮、打开生成文件按钮、打开文件夹按钮 | 1. 添加并选定至少 1 组匹配条件；<br>2. 勾选至少 1 个需要带回的字段 |

| **Processing** | 进度条平滑滚动（显示“索引中/比对中”及进度文字）；所有配置控件冻结 | 仅允许最小化窗口，界面控件处于忙碌阻断锁定状态 | 页面内所有输入框、下拉框、复选框、按钮全部禁用 | 等待计算与写入完成 |
| **Success** | 进度条完成；呈现【总行数 / 匹配成功 / 未匹配 / 重复冲突】四项统计仪表板；激活文件操作区 | 导航栏、重新配置各参数、「打开生成文件」、「打开所在文件夹」、重新开始匹配 | 无（配置仍可修改以进行下一轮匹配） | 1. 打开结果文件验证；<br>2. 查看未匹配或重复统计详情 |

## 6. 弹窗与异常交互规范 (Dialogs & Exception Feedback)

### 6.1 目标文件已存在确认覆盖弹窗
- **触发时机**：点击「开始格式统一」或「开始数据匹配」时，系统检测到输出路径已存在同名文件。
- **对话框类型**：Windows 模态确认对话框（Modal Dialog）。
- **内容规范**：
  - **标题**：`输出文件已存在`
  - **图标**：警告（Warning）图标。
  - **正文**：`文件 "[完整路径]" 已经存在。是否覆盖该结果文件？`
  - **按钮选项**：
    - **「覆盖」**：明确确认覆盖该结果文件，继续执行。
    - **「另存为...」**：唤起另存为对话框，让用户指定新文件名。
    - **「取消」**：终止本次执行，返回配置界面。

### 6.2 输出文件严禁覆盖源文件拦截
- **触发时机**：当输出路径被用户手动指定为主表源文件或对照表源文件时。
- **交互形式**：在输出路径下方即时显示红色警示文字：`* 禁止覆盖输入源文件，请选择其他输出文件名或路径`，并强制禁用「开始」按钮，无需等待点击。

### 6.3 文件被占用错误反馈
- **触发时机**：执行读写时，源文件或目标文件已被本地 Excel 或其他程序独占打开。
- **提示内容**：`无法读写文件："[文件名]" 正被其他程序占用。请在 Excel 中关闭该文件后重试。`
- **按钮**：`[重试]`、`[关闭]`。

### 6.4 文件格式与内容异常
- **非 .xlsx 文件拖入**：鼠标指针显示禁止图标，松开后在输入框下方短暂弹出气泡提示：`TabularStudio 第一版仅支持 .xlsx 格式文件`。
- **空工作表 / 表头行越界**：若用户指定的表头行大于该 Sheet 最大数据行数，下方红字提示：`所选表头行超出工作表有效范围（当前最大数据行: N）`，开始按钮置灰。
- **无有效匹配条件**：未配置条件或字段下拉框为空时，禁用开始按钮，并以 Tooltip 提示：`请至少指定一组有效的匹配字段`。
- **未选择带回字段**：带回字段数量为 0 时，禁用开始按钮，Tooltip 提示：`请至少勾选一个需要从对照表带回的字段`。

## 7. 跨功能页面流转规范 (Cross-Feature Workflow)

### 7.1 “作为主表送入数据匹配”完整流转
1. **触发源**：「格式统一」页面在 `Success` 状态下展示的快捷按钮 `[ 作为主表送入数据匹配 -> ]`。
2. **交互时序**：
   ```mermaid
   sequenceDiagram
       autonumber
       actor User as 用户
       participant Page1 as 格式统一页面
       participant Shell as App Shell (导航控制器)
       participant Page2 as 数据匹配页面

       User->>Page1: 点击 [作为主表送入数据匹配 ->]
       Page1->>Shell: 发起页面跳转请求(Payload: 输出文件完整路径)
       Shell->>Shell: 切换左侧导航高亮至 [数据匹配]
       Shell->>Page2: 激活并传递主表文件路径
       Page2->>Page2: 将路径填入主表输入框
       Page2->>Page2: 自动触发主表解析与 Sheet 填充
       Page2->>Page2: 状态由 Initial 转为 File Loaded
       Page2-->>User: 展现数据匹配界面，焦点定位在对照表选择区
   ```
3. **用户体验收益**：无需用户手动去文件夹寻找刚生成的 `xxx_格式统一.xlsx` 并再次浏览选择，形成极度顺畅的二步式流水线体验。

## 8. 非目标界面与界面禁区 (Out of Scope)

为确保绝对不超出 MVP 范围，以下界面元素和交互属于**严格禁止事项**：
1. **无用户登录 / 注册 / 授权界面**：没有任何个人中心、在线激活或账号相关元素。
2. **无云端同步 / 远程存储 / 网络配置界面**：没有任何 URL 配置、API 密钥输入、网络状态指示。
3. **无数据库连接配置窗口**：不提供连接 MySQL/SQL Server/Oracle 等配置界面。
4. **无模糊匹配 / 算法阈值调节滑动条**：不提供 Levenshtein / 拼音相似度 / 模糊滑块等配置项（MVP 仅支持多字段精确匹配）。
5. **无非 .xlsx 文件格式选择器**：文件对话框一律严格限制 `.xlsx`，不出现 `.xls`、`.csv`、`.txt` 等后缀。
6. **无表格就地单元格编辑器**：预览区仅为只读样本展示，不做 Excel 级全量编辑网格。
7. **无固定美化格式套件选择器**：不提供模板配色、换肤美化等装饰性界面。

## 9. UI 验收标准清单 (Acceptance Criteria Checklist)

WPF 开发人员在完成页面编码后，应逐项核对本验收清单：

### 9.1 全局与 App Shell
- [ ] 窗口启动居中，默认尺寸 1100×720，最小尺寸 960×640。
- [ ] 左侧导航仅包含「格式统一」与「数据匹配」两项，选中态清晰高亮。
- [ ] 页面切换时已输入内容和状态保持完好，不丢失数据。
- [ ] 底部常驻“离线环境已就绪”及版本信息。

### 9.2 格式统一页面
- [ ] 支持点击「浏览」选择 `.xlsx` 文件，支持拖拽 `.xlsx` 文件。
- [ ] 能够解析并下拉选择工作表，能够设定表头所在行。
- [ ] 预览表格能正确展示选定工作表的前 20 行数据，列名随表头行自适应更新。
- [ ] 8 项标准化能力复选框齐全且默认勾选，保留原有业务格式与公式提示常驻。
- [ ] 输出路径默认展示 `源文件名_格式统一.xlsx`，支持「更改保存路径...」。
- [ ] 禁止输出覆盖源文件。
- [ ] 输出文件已存在时，弹出覆盖确认模态框（覆盖 / 另存为 / 取消）。
- [ ] 处理中进度条平滑运转，配置控件锁定。
- [ ] 处理成功后展示耗时与行数，可点击「打开生成文件」与「打开所在文件夹」。
- [ ] 点击「作为主表送入数据匹配」可直接跳转并自动将结果文件装载为主表。

### 9.3 数据匹配页面
- [ ] 主表与对照表均支持独立选择 `.xlsx` 文件、选择 Sheet、指定表头行及数据预览。
- [ ] 支持勾选「与主表使用同一个文件」以实现同文件不同 Sheet 的精确匹配。
- [ ] 动态匹配条件支持 1～N 条，可自由添加与删除（至少保留 1 条）。
- [ ] 多条件之间固定明确展示 `AND` 逻辑。
- [ ] 主表与对照表字段下拉框能够正确列出各自表头字段。
- [ ] 允许从对照表勾选带回 1 个或多个字段，提供字段关键字即时搜索，提供全选/反选。
- [ ] 具备“自动修复常见匹配差异”复选框（默认勾选）。
- [ ] 具备“生成匹配状态列”复选框（默认勾选，默认列名“匹配状态”）。
- [ ] 动态展示当前匹配关系单行摘要。
- [ ] 输出路径默认展示 `主表文件名_匹配结果.xlsx`，禁止覆盖源文件。
- [ ] 处理成功后清晰统计总行数、匹配成功行数、未匹配行数、重复冲突行数。
- [ ] 处理成功后可点击打开生成文件及打开所在文件夹。
- [ ] 各页面在 Initial、File Loaded、Ready、Processing、Success、Error 6 种状态下的控件启闭符合状态矩阵。
