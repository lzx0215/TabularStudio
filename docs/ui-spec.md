## 1. 文档定位与原则

1. **界面规格与事实来源**：本文档记录 TabularStudio 已确认的 UI 页面方案，作为后续 WPF 页面实现、控件布局、交互逻辑与状态流转的唯一规范。本文档已通过 Project Owner 审批，处于 `Approved UI Baseline` 状态。
2. **严格对齐需求**：所有页面元素和交互行为严格遵循 `docs/requirements.md`，不得反向扩大产品范围。
3. **区分「已确认基线」与「实现建议」**：
   - **已确认基线 (Confirmed Baseline)**：经 Project Owner 及 `docs/requirements.md` 明确确认的页面结构、功能布局、核心控件、处理能力、关键安全拦截与数据预览规则，是 UI 必须满足的硬性边界。
   - **实现建议 (Implementation Recommendation)**：为了支撑 WPF 落地、提升使用便捷性而由 UI Developer 提出的推荐方案（如具体窗口尺寸、8px 网格、文件拖拽、反选按钮、快捷跳转入口等）。此类内容在文中明确标注为【实现建议】，不作为强约束的产品基线，开发与验收时可灵活适配或视 Project Owner 反馈调整。
4. **职责分离**：
   - 本文档只定义 UI 布局、控件类型、交互响应、视觉状态和错误反馈。
   - 不包含 ClosedXML 实现细节、数字/日期转换算法、匹配键比对算法、C# 接口/DTO 代码（具体处理规则由 `docs/processing-rules.md` 规定，调用契约由 `docs/contracts.md` 规定）。
5. **范围冻结**：覆盖已确认的**格式统一**、**数据匹配**及 2026-09-10 新增的**表格对比**，不包含未确认功能或在线服务。表格对比由 Owner 本次授权 Codex 完成 UI；此前页面规格仍适用。

### 2026-09-10 表格对比页面增量

在左侧纵向导航中提供“表格对比”，保留页面状态。工作区提供表一、表二文件选择与工作表选择（CSV 无需选择），无需表头行或匹配键配置。展示比较口径、开始/取消/导出按钮、结论、两表范围、差异总数及前 1000 条坐标/类型/值；全部差异可导出。文本加引号并显示换行/Tab 转义，区分空白与空格。本段三入口增量覆盖历史双入口限制，其余 #54 界面与交互保留。

读取期间禁用输入，比较/导出期间提供取消。更换输入或工作表清除旧结论；失败和取消不能显示一致。导出失败保留已完成结果，可重试。导出后显示可复制的完整报告路径。具体规则见 `positional-comparison.md`。

## 2. 全局窗口架构与 App Shell

### 2.1 窗口规格与视觉基调

#### 2.1.1 视觉风格与主题【已确认基线】
- **视觉主题**：浅色雾面工作台。暖灰绿背景、古铜金强调、细线分区、小圆角细描边控件。
- **配色说明**：应用背景 `#F5F5F0`，侧栏 `#ECEFE8`，内容面板 `#FCFCF9`，分割线 `#D5D9D1`，主文字 `#2D3631`，强调色 `#826B40`。金色只用于当前导航、主要操作、选中控件和少量装饰。
- **范围限制**：页面结构和功能布局仍以已确认方案为准；不增加深色模式（Dark Mode）或主题切换机制。
- **窗口模式**：Windows 本地原生桌面应用窗口，支持最小化、最大化/还原、关闭。不重写窗口系统。

#### 2.1.2 窗口尺寸与布局【实现建议】
- **【实现建议】推荐尺寸**：
  - 默认启动尺寸建议：`1100 × 720` 像素（居中启动）。
  - 最小尺寸建议：`960 × 640` 像素（防止低分辨率屏幕下控件拥挤或截断）。
- **【实现建议】布局网格**：建议遵循 8px 网格基准进行控件内边距与外间距对齐。
- **自适应响应**：支持全屏/最大化，主内容区表格与配置卡片按比例自适应伸缩。

### 2.2 App Shell 布局骨架【已确认基线】

界面整体采用经典的「左侧导航栏 + 右侧主内容区 + 底部状态条」布局：


### 2.3 导航系统与行为

1. **导航菜单项【已确认基线】**：
   - **格式统一 (Format Normalization)**：处理单个 Excel 表格的格式清洗与规范化。
   - **数据匹配 (Data Matching)**：将主表与对照表基于多条件精确匹配并合并字段。
2. **导航切换与状态保持**：
   - 点击导航项即时切换主工作区内容【已确认基线】。
   - **【实现建议】页面状态缓存策略**：切换功能页面时，建议保留各页面的输入状态与配置缓存（ViewModel 不随 Tab 切换而销毁），避免用户在两个功能之间来回切换时丢失已选文件路径或已配置条件。
3. **底部全局状态栏**：
   - 左侧：当前系统全局状态或提示信息（例如：“就绪”、“正在处理...”）【已确认基线】。
   - 右侧：环境标识，展示离线安全状态【已确认基线】。
   - **【实现建议】底部具体文案**：右侧建议固定文案为“离线环境已就绪”，左侧提示文案如“就绪”、“处理完成”作为推荐参考，开发时可依具体动作微调。

## 3. 功能一：格式统一 (Format Normalization)

用户选择 1 个 `.xlsx` 文件，对选定工作表做格式统一，并生成新文件。

### 3.1 页面布局线框图

### 3.2 界面控件与交互说明

#### 3.2.1 数据源选择区
1. **文件选择输入框【已确认基线】**：
   - 单行文本框（只读显示完整物理路径）。
   - 提供「浏览...」按钮，唤起 Windows 原生 `OpenFileDialog`，筛选条件固定为 `Excel 工作簿 (*.xlsx)|*.xlsx`。
   - **【实现建议】文件拖拽**：建议支持直接将 `.xlsx` 文件拖拽至文件框或数据源区域内完成载入；拖入非 `.xlsx` 文件时提示格式不支持。
2. **工作表选择下拉框 (ComboBox)【已确认基线】**：
   - 文件加载成功后自动解析并填充该文件所有 Sheet 名称。
   - 切换 Sheet 会触发数据预览区重新读取前 20 行刷新。
   - **【实现建议】默认选中第一个 Sheet**：建议文件加载后默认自动选定第一个 Sheet，减少用户额外点击。
3. **表头所在行设置 (NumericUpDown / 数字输入框)【已确认基线】**：
   - 默认为 `1`。
   - 允许用户微调（最小值为 1，步长为 1）。
   - 当用户更改表头行时，数据预览表格的列标题将同步重新识别，并将所选行作为列头。

#### 3.2.2 标准化规则选择区【已确认基线】
根据 `docs/requirements.md` 5.2 节已确认能力，提供以下标准化规则列表（Checklist）：
1. **清理前后空格**：可选规则默认不启用，用户可按需勾选。
2. **清理 Tab、换行、隐藏字符**：可选规则默认不启用，用户可按需勾选。
3. **全角 / 半角统一**：可选规则默认不启用，用户可按需勾选（针对字母、数字、英文符号）。
4. **Unicode 标准化**：可选规则默认不启用，用户可按需勾选。
5. **普通数字安全统一**：可选规则默认不启用，用户可按需勾选。
6. **明确日期安全统一**：可选规则默认不启用，日期/时间类型默认不处理；用户按需勾选后才进行处理。
7. **保留前导 0 编号**：默认勾选并**置灰锁定**（用户不可取消；UI 明确提示为始终开启的数据安全保护，防止工号/身份证等前导 0 丢失）。
8. **保留长数字文本**：默认勾选并**置灰锁定**（用户不可取消；UI 明确提示为始终开启的数据安全保护，防大整数截断失真）。
- **保护说明文本【已确认基线】**：卡片底部常驻提示——*“处理时公式保持不变；前导 0 与长数字保护始终启用（锁定开启）；尽量保留现有业务格式，不重新套固定美化模板。”*

#### 3.2.3 数据预览区
1. **数据预览规则【已确认基线】**：
   - **默认读取前 20 行**：选定工作表后，默认仅读取前 20 行数据渲染于预览表格中。
   - **核对目的明确**：预览仅用于用户核对表头识别位置和数据概貌，**绝对不限制实际处理的数据行数**。
   - **只读模式**：仅供查看，禁止就地编辑。支持横向与纵向平滑滚动。
   - **列名规则**：列标题由设定的「表头所在行」决定。
2. **【实现建议】空态与占位提示**：
   - 未加载文件前，表格区域建议展示居中浅灰引导提示：“请先选择 Excel 文件以预览数据”。
   - 若用户指定的表头行中某列为空，建议展示默认占位列名（如“第 A 列”）。

#### 3.2.4 输出与执行控制区
1. **输出路径展示与配置【已确认基线】**：
   - 默认文件名：`原文件名_格式统一` + 当前输入文件扩展名（MVP 阶段为 `.xlsx`）。
   - 输出目录规则（输出目录方案 A）：
     - 用户尚未指定过输出目录时，默认保存在该输入文件所在目录。
     - 用户通过「更改保存路径」指定目录后，本机记住该目录；关闭应用再打开仍然有效。
     - 格式统一与数据匹配共用同一个本机记住的输出目录。
     - 之后换输入文件、再次启动，默认输出目录均使用记住的那个目录。
     - 最末端文件名必须重新按当前输入文件自动生成，禁止沿用上一次的完整文件名。
     - 切换输入文件时，禁止把输出路径整段锁成上一次的完整路径。
     - 若记住的输出目录在磁盘上不存在，则该次回退到当前输入文件所在目录。
   - 提供「更改保存路径...」按钮，唤起 `SaveFileDialog`（限定 `.xlsx` 格式）。
   - **安全约束**：输出路径禁止与当前输入文件完全一致（若一致则禁用开始按钮并红字提示“输出文件不得覆盖源文件”）。
   - **同名文件防护**：禁止静默覆盖已有结果文件；检测到输出文件已存在时弹出确认对话框（提供「覆盖」「另存为...」「取消」）。
2. **进度反馈条 (ProgressBar)【已确认基线】**：
   - 提供执行中进度反馈（进度条及阶段状态文字）。
   - 处理未开始或空闲时显示 0% 或处于隐匿/平整状态。
3. **操作按钮组**：
   - **「开始格式统一」主操作按钮【已确认基线】**：重点按钮。文件未就绪或正在处理时禁用。
   - **后置快捷操作按钮【已确认基线】**：
     - **「打开生成文件」按钮**：成功后启用，使用 Windows 系统默认程序打开结果文件。
     - **「打开所在文件夹」按钮**：成功后启用，在资源管理器中定位并选中该文件。
     - **「作为主表送入数据匹配 ->」快捷按钮**：成功后展现的快捷联动入口。点击后自动切换至「数据匹配」页面，并将刚生成的格式统一结果文件自动填入数据匹配的主表输入项中，触发主表 Sheet 解析与预览；不自动开始匹配，后续匹配条件、带回字段等仍由用户自行配置。

### 4.2 界面控件与交互说明

#### 4.2.1 双表输入选择区
1. **主表 (Master Table) 设置【已确认基线】**：
   - 文件选择框（单行只读路径 +「浏览...」按钮）。
   - 工作表 ComboBox 与表头所在行 NumericUpDown。
   - **【实现建议】文件拖拽与默认 Sheet**：建议支持 `.xlsx` 文件拖拽，加载后默认选定首个 Sheet。
2. **对照表 (Reference Table) 设置【已确认基线】**：
   - 允许来自两个不同的 `.xlsx` 文件，也允许来自同一个 `.xlsx` 文件中的不同 Sheet。
   - 独立的工作表 ComboBox 与表头所在行 NumericUpDown。
3. **"与主表使用同一个文件"复选框【已确认基线】**：
   - 在对照表区域放置「与主表使用同一个文件」复选框（CheckBox）。
   - **交互行为**：
     - 勾选时：对照表文件路径文本框锁定为主表路径并置灰，对照表的「浏览...」按钮置灰禁用；对照表 Sheet 下拉框自动读取主表文件下的所有 Sheet 供用户独立选择，以便实现同文件跨 Sheet 精确匹配。
     - 取消勾选时：恢复独立的对照表文件路径浏览选择。
   - **业务行为不变**：此交互仅简化"同一个 `.xlsx` 不同 Sheet"的选择操作，不改变 `requirements.md` 已确认的匹配规则和处理逻辑。
4. **数据预览规则【已确认基线】**：
   - 主表与对照表均提供数据预览，默认读取各自选定工作表的前 20 行数据。
   - 预览仅用于核对表头和数据概貌，不限制实际处理的数据行数。
   - **【实现建议】预览交互形式**：建议在主表与对照表旁分别提供「数据预览」按钮，点击后唤起浮层模态弹窗或侧边抽屉展示前 20 行样本。

#### 4.2.2 动态匹配条件配置区 (Matching Conditions)【已确认基线】
1. **条件列表结构 (1～N 条)**：
   - 每一行代表一组相等条件：`[主表字段下拉框] = [对照表字段下拉框] [删除按钮]`。
   - 主表字段下拉框：自动从主表选定 Sheet 与表头行中提取所有非空列名。
   - 对照表字段下拉框：自动从对照表选定 Sheet 与表头行中提取所有非空列名。
2. **多条件逻辑关系**：
   - 各条件之间固定为 `AND`（且）逻辑，界面显式呈现 `AND` / `且` 标识。
   - 必须所有条件同时符合才算匹配成功，不支持模糊匹配。
3. **增删控制**：
   - 点击「+ 添加匹配条件」按钮可追加一行新条件。
   - 每行末尾提供「删除」按钮。
   - **约束**：至少保留 1 条匹配条件；当仅剩 1 条条件时，该条件的「删除」按钮置灰禁用。

#### 4.2.3 带回字段选择区 (Return Fields)
1. **字段列表与多选【已确认基线】**：
   - 完整列出对照表的所有可用字段供勾选。
   - 用户可选择 1 个或多个需要从对照表带回的列，匹配成功后追加至主表右侧。
2. **列名重名处理规则【已确认基线】**：
   - 当带回字段与主表既有列重名时，界面与系统严格按需求 6.2.3 规范处理（自动重命名为 `字段名_匹配`、`字段名_匹配2` 等），不覆盖主表原有列。
3. **【实现建议】带回字段辅助交互**：
   - **字段关键字搜索框**：建议在列表顶部提供搜索过滤框（TextBox），输入关键字即时过滤下方字段。
   - **全选与反选**：建议提供「全选」与「反选」快捷文本按钮，以及“已选 M / N 项”的计数指示。

#### 4.2.4 高级选项与容错配置【已确认基线】
1. **自动修复常见匹配差异**：
   - 复选框，默认勾选。
   - 含义：比较匹配键时自动消除空格、全半角、文本/数值类型差异、日期格式差异；仅用于内存比较，不改源数据。
2. **生成匹配状态列**：
   - 复选框，默认勾选。
   - 列名配置框：默认为「匹配状态」，允许用户就地修改列名。
   - 状态取值：匹配成功、未匹配、重复、匹配键为空。
3. **容错策略说明**：
   - 常驻提示：对照表出现重复匹配键时，对应主表记录返回字段留空，状态标为“重复”，不中止任务，不自动取首尾行；未匹配时返回字段留空。

#### 4.2.5 匹配关系摘要预览条【实现建议】
- **【实现建议】摘要条形式**：建议在核心配置区下方常驻单行卡片，动态拼接当前配置的人类可读摘要（例如：`匹配规则: [主表.客户ID = 对照.客户编码] | 带回 2 个字段 | 启用状态列`），方便用户一目了然核对。

#### 4.2.6 输出与执行控制区
1. **输出路径配置【已确认基线】**：
   - 默认文件名：`原文件名_匹配结果` + 主表输入文件扩展名（MVP 阶段为 `.xlsx`，原文件名指主表文件的原文件名）。
   - 输出目录规则（输出目录方案 A）：
     - 与格式统一共用同一个本机记住的最近一次输出目录。
     - 用户尚未指定过输出目录时，默认保存在主表所在目录。
     - 用户通过「更改保存路径」指定目录后，本机记住该目录；关闭应用再打开仍然有效。
     - 之后换主表文件、再次启动，默认输出目录均使用记住的那个目录。
     - 最末端文件名必须重新按当前主表文件自动生成，禁止沿用上一次的完整文件名。
     - 切换主表文件时，禁止把输出路径整段锁成上一次的完整路径。
     - 若记住的输出目录在磁盘上不存在，则该次回退到当前主表所在目录。
   - 提供「更改保存路径...」按钮，唤起 SaveFileDialog。
   - **安全约束**：禁止覆盖主表文件或对照表文件。
   - **同名文件防护**：禁止静默覆盖已有结果文件；检测到输出文件已存在时弹出确认对话框（提供「覆盖」「另存为...」「取消」）。
2. **执行按钮与进度反馈【已确认基线】**：
   - 「开始数据匹配」主操作按钮。
   - 提供进度反馈条及阶段文字。
3. **匹配结果统计指示卡片【已确认基线】**：
   - 处理成功后，固定显式呈现 5 项统计面板（即使数量为 0 也正常显示 0 行，严禁将“匹配键为空”合并进“未匹配”）：
     - **总计**（如 `1,580` 行）
     - **匹配成功**（如 `1,420` 行）
     - **未匹配**（如 `130` 行）
     - **重复**（如 `30` 行）
     - **匹配键为空**（如 `0` 行）
4. **后置快捷操作按钮【已确认基线】**：
   - 成功状态下提供「打开生成文件」与「打开所在文件夹」快捷按钮。

## 5. 主要页面状态机规格 (Page States Specification)

为确保 WPF 界面数据绑定与视图状态（Visual State）严谨无死锁，对「格式统一」和「数据匹配」两页面分别统一规范 6 大生命周期状态。

### 5.1 状态枚举定义【已确认基线】
1. **Initial / Empty**：初始空状态（无文件载入）。
2. **File Loaded**：文件已载入，正在解析表头或部分配置缺失。
3. **Ready**：配置完整就绪，等待用户触发执行。
4. **Processing**：正在离线处理，展示进度反馈并阻断配置改动。
5. **Success**：处理圆满完成，展示结果统计与文件快捷操作。
6. **Error**：处理失败或输入校验阻断，展示明确错误原因与引导。

---

| 状态 | 界面显示内容 | 可用控件 (Enabled) | 禁用控件 (Disabled) | 用户下一步操作 |
| --- | --- | --- | --- | --- |
| **Initial / Empty** | 路径框为空；预览区显示占位提示；进度条隐匿；结果卡片隐匿 | 导航栏、文件「浏览...」按钮、【建议】拖拽区域 | Sheet 下拉框、表头行输入、规则复选框、输出路径更改、开始按钮、打开文件相关按钮 | 点击「浏览」选择 `.xlsx` 文件 |

## 6. 弹窗与异常交互规范 (Dialogs & Exception Feedback)

### 6.1 目标文件已存在确认覆盖弹窗【已确认基线】
- **触发时机**：点击「开始格式统一」或「开始数据匹配」时，系统检测到输出路径已存在同名结果文件。
- **对话框类型**：Windows 模态确认对话框（Modal Dialog）。
- **交互规范**：
  - 严禁静默覆盖已有文件。
  - 必须向用户提示文件已存在，并明确提供：
    - **「覆盖」**：明确确认覆盖该结果文件，继续执行。
    - **「另存为...」**：唤起另存为对话框，让用户指定新文件名。
    - **「取消」**：终止本次执行，返回配置界面。

### 6.2 输出文件严禁覆盖源文件拦截【已确认基线】
- **触发时机**：当输出路径被用户手动指定为主表源文件或对照表源文件时。
- **交互形式**：在输出路径下方即时显示红色警示文字：`* 禁止覆盖输入源文件，请选择其他输出文件名或路径`，并强制禁用「开始」按钮，阻断误操作。

### 6.3 文件被占用错误反馈【已确认基线】
- **触发时机**：执行读写时，源文件或目标文件已被本地 Excel 或其他程序独占打开锁定。
- **提示内容**：清晰告知用户 `文件正被其他程序占用，请在 Excel 中关闭该文件后重试`。
- **提供操作**：提供重试或取消。

### 6.4 格式与表头异常处理【已确认基线与实现建议】
- **非 .xlsx 文件拦截【已确认基线】**：文件对话框限定 `*.xlsx`；若通过拖拽等方式传入非 `.xlsx`，提示第一版仅支持 `.xlsx` 格式。
- **表头行越界【实现建议】**：若用户指定的表头行大于该 Sheet 最大数据行数，建议红字提示表头行超出范围，并禁用开始按钮。
- **配置缺失阻断【已确认基线】**：无有效匹配条件或未选择带回字段时，保持开始按钮禁用，并通过界面提示引导用户配置。

## 7. 跨功能页面流转规范【已确认基线】

### 7.1 "作为主表送入数据匹配"联动工作流
1. **需求依据**：`requirements.md` 第 7 节明确"格式统一后的结果可以继续作为数据匹配的主表；用户也可以跳过格式统一，直接进行数据匹配"。
2. **已确认交互行为**：
   - 在「格式统一」成功状态面板中提供快捷按钮 `[ 作为主表送入数据匹配 -> ]`。
   - 点击后：
     - 切换至「数据匹配」页面；
     - 将刚生成的格式统一结果文件自动填入数据匹配的主表文件输入框；
     - 自动触发主表 Sheet 解析与前 20 行数据预览；
     - 页面进入 `File Loaded` 状态。
   - **不自动开始匹配**：后续的对照表选择、匹配条件配置、带回字段勾选等操作仍由用户自行完成。
   - **交互时序**：
     ```mermaid
     sequenceDiagram
         autonumber
         actor User as 用户
         participant Page1 as 格式统一页面
         participant Shell as App Shell (导航控制器)
         participant Page2 as 数据匹配页面

         User->>Page1: 点击 [作为主表送入数据匹配 ->]
         Page1->>Shell: 发起页面跳转(携带输出文件完整路径)
         Shell->>Shell: 切换左侧导航至 [数据匹配]
         Shell->>Page2: 激活页面并将路径填入主表输入框
         Page2->>Page2: 自动触发主表 Sheet 解析与前20行预览
         Page2->>Page2: 页面进入 File Loaded 状态
         Page2-->>User: 展现数据匹配界面，等待用户配置对照表与匹配条件
     ```
3. **独立性保证**：即使不点击该快捷入口，用户完全可以在数据匹配页面自行浏览选取该文件；两者功能逻辑完全独立。

## 8. 非目标界面与界面禁区 (Out of Scope)【已确认基线】

为确保绝对不超出 MVP 范围，以下界面元素和交互属于**严格禁止事项**：
1. **无深色模式或主题切换**：MVP 仅支持泛化的 Windows 标准浅色主题，不提供主题切换下拉框或深色开关。
2. **无用户登录 / 注册 / 授权界面**：没有任何个人中心、在线激活或账号相关元素。
3. **无云端同步 / 远程存储 / 网络配置界面**：没有任何 URL 配置、API 密钥输入、网络状态指示。
4. **无数据库连接配置窗口**：不提供连接 MySQL/SQL Server/Oracle 等配置界面。
5. **无模糊匹配 / 算法阈值调节滑动条**：不提供 Levenshtein / 拼音相似度 / 模糊滑块等配置项（MVP 仅支持多字段联合精确匹配）。
6. **无非 .xlsx 文件格式选择器**：文件对话框一律严格限制 `.xlsx`，不出现 `.xls`、`.csv`、`.txt` 等后缀。
7. **无表格就地单元格编辑器**：预览区仅为只读样本展示，不做 Excel 级全量编辑网格。
8. **无固定美化格式套件选择器**：不提供模板配色、换肤美化等装饰性界面。

## 9. UI 验收标准清单 (Acceptance Criteria Checklist)

### 9.1 已确认基线验收清单 (Baseline Checklist - 必须满足)

- [ ] 窗口支持最小化、最大化、关闭，主工作区按比例自适应伸缩。
- [ ] 左侧导航仅包含「格式统一」与「数据匹配」两项，选中态清晰高亮。
- [ ] 格式统一功能：
  - [ ] 仅支持 `.xlsx` 文件输入，能够解析并选择工作表，支持指定表头行。
  - [ ] 数据预览默认读取前 20 行，仅用于核对表头和数据概貌，不限制实际处理行数。
  - [ ] 8 项标准化能力齐全（前 6 项可选规则默认不启用、可由用户按需勾选，前导 0 与长数字保护默认勾选且置灰锁定不可取消），保留原有业务格式与公式提示常驻。
  - [ ] 输出路径配置符合输出目录方案 A（首次使用默认为输入文件同级目录；用户通过「更改保存路径」指定后本机记住该目录；换文件或重启应用保持输出目录并随当前文件自动重新生成文件名；记住目录不存在时安全回退至输入文件目录），支持「更改保存路径...」。

  - 可用宽度 W < 1000 DIP：文件列表（188 DIP），右侧上方为文件预览、下方为整批规则（高度比约 3:2，内部滚动）。
- **底栏执行**：固定于工作区下方，包含整批输出目录设置、开始处理主按钮及后置结果操作快捷按钮。

### 3. 数据匹配页面布局 (DataMatchingView)
- **页头与配置条**：左侧页面标题与副标题，右侧集成处理配置条（配置下拉、应用、保存配置…、删除）。
- **上下双表预览**：主表在上、对照表在下，各占预览区约一半高度；各自包含文件浏览、工作表与表头行配置及只读数据表格。
- **右侧设置列**：独立垂直滚动面板（W ≥ 1040 DIP 占 340 DIP，W < 1040 DIP 占 300 DIP）：
  - 匹配条件列表：每条条件按分行排版（序号/删除 -> 主表字段 -> 等于对照表字段），底部紧接“＋ 添加匹配条件”。
  - 带回字段列表：包含搜索过滤、全选、反选、已选计数及限高内部滚动。
  - 可折叠区域：“主表筛选”与“比较与状态列”默认折叠并展示摘要文本，筛选启用或错误时自动展开。
- **底栏执行**：固定于底部，包含结果文件路径设置、开始匹配主按钮、五项处理统计与后置结果操作。

### 4. 表格对比页面布局 (TableComparisonView)
- **顶部双源选择**：表一与表二对称横向排版，紧凑显示文件路径与工作表选择。
- **比较口径与结论**：居中提示卡片说明比较规则；下方展示差异统计与上限提示。
- **全宽差异表**：差异明细 DataGrid 占满工作区宽度，完整呈现位置、表一类型/值、表二类型/值，支持横纵局部平滑滚动。
- **底栏执行**：固定底部取消、导出全部差异及开始对比按钮。
